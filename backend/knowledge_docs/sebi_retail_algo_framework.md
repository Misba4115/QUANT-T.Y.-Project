# Educational summary: retail algorithmic-trading safeguards

This is a curated educational summary, not legal or investment advice. The linked SEBI master circular is the authority.

Research indicators and simulations should remain separate from order execution. The application should show assumptions, time ranges, data quality, and the distinction between backtested, synthetic, and live observations. It should not promise returns or present past simulated performance as a guarantee of future performance.

Any future broker execution path requires explicit user confirmation, revocable authorization, complete audit records, and provider-specific compliance review. The Phase 3 backlog implements educational analysis only; it does not place trades.
